Robotics Picasso 绘图机器人

Kinematics / Control

在 EECS 567 Robotics Modeling and Control 中设计并仿真关节式绘图机器人。 系统将图片轮廓或用户输入字符转换为画板坐标系下的轨迹，再映射到机器人工作空间并生成可执行关节空间运动。

  • 使用 Freeman Chain Code 提取单连通图像轮廓，并在轨迹生成前进行轮廓平滑。
  • 为图片、大小写英文字母和阿拉伯数字规划画板坐标系下的绘图路径。
  • 实现逆运动学、关节空间插值、正运动学验证，以及关节角和加速度分析。
  • 设计混合轨迹/力控制策略，使绘图过程中笔尖始终垂直画板。
